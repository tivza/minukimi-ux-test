# MINUKIMI visual system v1.1

## Core
- Light luxury-tech dating UI. Clean, quiet, editorial.
- Display voice: elegant serif. Functional voice: clean sans-serif.
- Bright color belongs primarily to the signature heart.

## Signature heart
Canonical geometry is locked. Two separate halves form one heart only by translation; paths never morph or get redrawn.
- Left: pink -> violet
- Right: violet -> blue -> cyan
- Rest: separate halves
- Approach: both halves translate inward
- Connected: each half translates 9px inward
- Pass: one half exits the card
- The heart lives directly over the blurred/darkened photo bottom. No matte panel underneath.

## Profile card hierarchy
1. Face/photo
2. Name + age
3. City + profession
4. IN MY HEAD, I'M... (max 2 lines)
5. Signature heart

## Main photo hard gate
- Exactly one clear human face.
- Reject no-face, multiple-face, too-small-face images.
- Face must stay above the lower text/gesture zone.
- Show live face/shoulders safe-zone guide.

KIMI is a fast exit with confirmation. Also expose normal end, block and report actions.
